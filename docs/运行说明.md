# 声音数据处理工作台运行说明

## 推荐启动方式

双击 `start_client.bat`。它会依次确认前端构建产物、启动 FastAPI 网关和独立 SQLite Worker，并打开 `http://127.0.0.1:8000/pipeline`。

## 手动启动方式

先运行 `scripts\start_backend.bat`，再另开一个终端运行 `scripts\start_worker.bat`。只启动 FastAPI 不会消费队列，任务会保持在“排队中”。

## 停止方式

双击 `stop_client.bat`，会同时停止网关和 Worker。运行日志位于 `local_tools/cache/client_runtime`。

## 数据边界

当前正式版只处理 `voice_clone`。输出批次目录包含 `manifest.jsonl`、质量报告、状态文件、工具版本、checkpoint 和 Agent Graph 追溯信息，不包含 SoVITS 训练过程。

## MSST 去混响

处理配置中勾选“运行 MSST 去混响”后，会使用 `local_tools/models/msst` 下的指定模型。当前只支持 `deverb_bs_roformer_8_256dim_8depth`。

MSST 运行时不是基础环境必需依赖。未安装运行时或模型配置不完整时，选择“阻断任务并报错”会停止任务；选择“跳过 MSST”会继续执行后续 FFmpeg、VAD 和质量治理流程。

## 下载可选模型

双击项目根目录的 `download_models.bat`，可选择下载 Qwen、faster-whisper-small 或 MSST 去混响模型。模型会保存到 `local_tools/models`，不会修改原始音频。

## 开发辅助脚本

- `scripts/build_client.bat`：重新构建前端。
- `scripts/start_frontend.bat`：启动 Vite 开发服务。
- `scripts/start_backend.bat`：只启动 FastAPI。
- `scripts/start_worker.bat`：只启动 SQLite Worker。
- `scripts/run_cli_smoke.bat <音频目录>`：用命令行跑一次本地音频目录。
